Desenvolver uma aplicação em C++ para monitoramento de um sensor de chama utilizando Linux embarcado na placa STM32\+MP157\+C-\/\+DK2.

O programa realiza a leitura digital do sensor através de um GPIO e identifica mudanças no estado de detecção de chama.\hypertarget{md_README_autotoc_md3}{}\doxysubsection{\texorpdfstring{2. Hardware utilizado}{2. Hardware utilizado}}\label{md_README_autotoc_md3}

O pino D2 corresponde ao GPIO PE1 da STM32\+MP1.

Na configuração Linux utilizada\+:


\begin{DoxyItemize}
\item Controlador\+: {\ttfamily /dev/gpiochip4}
\item Linha GPIO\+: {\ttfamily 1}
\item Direção\+: entrada digital
\end{DoxyItemize}

A numeração dos dispositivos GPIO pode variar conforme a configuração do sistema operacional.\hypertarget{md_README_autotoc_md5}{}\doxysubsection{\texorpdfstring{4. Funcionamento}{4. Funcionamento}}\label{md_README_autotoc_md5}
O sensor apresenta uma saída digital com dois estados\+:


\begin{DoxyItemize}
\item {\ttfamily 0}\+: chama detectada
\item {\ttfamily 1}\+: nenhuma chama detectada
\end{DoxyItemize}

Esses estados foram confirmados experimentalmente.

A aplicação monitora continuamente o sensor, realizando leituras a cada 200 milissegundos.

As mensagens são exibidas somente quando ocorre uma mudança no estado de detecção.

Exemplo de execução\+: \begin{DoxyVerb}Monitoramento iniciado.
[INFO] Nenhuma chama detectada.
[ALERTA] CHAMA DETECTADA!
[INFO] Nenhuma chama detectada.
\end{DoxyVerb}

O programa permanece em execução até ser interrompido com {\ttfamily Ctrl+C}.\hypertarget{md_README_autotoc_md10}{}\doxysubsection{\texorpdfstring{9. Implementação}{9. Implementação}}\label{md_README_autotoc_md10}
A aplicação utiliza a interface GPIO Character Device v2 do kernel Linux.

A comunicação com o GPIO é realizada através de chamadas {\ttfamily ioctl()}, utilizando a interface disponibilizada em {\ttfamily linux/gpio.\+h}.

Essa abordagem permite a leitura do sensor sem depender diretamente da biblioteca libgpiod.\hypertarget{md_README_autotoc_md11}{}\doxysubsection{\texorpdfstring{10. Documentação Doxygen}{10. Documentação Doxygen}}\label{md_README_autotoc_md11}

O sensor fornece apenas uma saída digital, não permitindo obter diretamente valores contínuos de intensidade luminosa.

A detecção depende da sensibilidade do módulo e das condições do ambiente.

O projeto possui finalidade acadêmica e não substitui sistemas certificados de detecção e prevenção de incêndios.
