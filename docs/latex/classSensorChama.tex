\doxysubsection{Detailed Description}
Interface C++ para um sensor de chama digital. 

A classe realiza a comunicacao com o GPIO PE1 da STM32\+MP1 atraves da interface GPIO do kernel Linux.

O sensor apresenta nivel logico baixo (0) quando detecta uma chama e nivel alto (1) quando nao detecta.
